- 月付 + 优惠码 = **79.2 元/月**

## 新加坡原生 IP VPS：官网公开全价的机房，六档怎么选

新加坡是官网购物车页面把六档价格全部摊开的机房，也是很多人搜“丽萨主机价格”时最先看到的入口。

官方描述写得很直白：“非大陆直连优化网络，建议中转使用”，并给了中转建议——**经香港中转延迟约 30ms，经日本中转约 70ms**。这句话决定了它的用法：它是一台海外落地机，不是给国内用户直连的机器。

第三方测评的记录可以作为参考：流媒体可解锁新加坡区 Netflix、YouTube、TikTok、ChatGPT，磁盘 IO 约 431MB/s，海外节点之间网络稳定性不错，大陆方向稳定性一般。路由上，电信去程绕美国圣何塞、洛杉矶到新加坡，联通走 AS4837，移动走 CMI，三条都不是大陆优化线路。测评作者的结论也是“建议拿来做中转”。

六档怎么选，答案比想象中简单：

- **只想低成本拿一个新加坡原生 IP**：基础版 68 元/月，300Mbps、6000GB 流量，1 核 1G 跑 TikTok 环境、Shopee 店铺、流媒体完全够用。它标着“限售 20 台”，属于促销位。
- **要跑多个账号或需要更宽的内存余量**：进阶版 88 元/月，2 核 2G、500Mbps、10000GB。多花 20 元换双倍 CPU 内存和接近翻倍的带宽，是六档里性价比最高的一次升级。
- **流量是硬约束、速度不敏感**：不限流量 Lite 398 元/月，2 核 2G、200Mbps 但不限流量。只有当你每月真的会跑掉几 TB 时才划算，否则进阶版的 10TB 已经很难用完。
- **年付**：466 元/年，折合 38.8 元/月，比月付 68 元省 350 元。代价是流量从 6000GB 降到每月 2000GB，配置同为 1 核 1G。跑轻量业务的人这笔账很划算，跑采集或大流量传输的人会被流量卡住。

豪华版 388 元/月和 Pro 898 元/月属于另一个量级，4 核 4G 配 1000Mbps 或 80G 硬盘，适合把新加坡当区域业务节点而不是单账号环境的小团队。个人用户买这两档，多出来的算力大概率闲置。

## 同样 1 核 1G，为什么有的 68 元一月、有的 199 元一年

这个价差不是随便定的，主要来自 IP。

机房 IP 是批量采购的共享段，单价低；住宅 IP 要从当地 ISP 手里拿，资源稀缺、维护成本高。所以家宽 VPS 普遍比同配置机房 VPS 贵 2 到 5 倍。一个直观对比：美国 CN2 GIA 机房 VPS 基础版月付 35 元，同配置的美国 9929 双 ISP 家宽精简版月付 68 元，差价接近一倍，多出来的钱买的是 IP 属性。

第二层价差来自线路。9929 是精品网，三网回程优化，第三方测评汇总的口径是美国洛杉矶机房三网平均延迟约 172ms；4837 走普通国际线路，带宽给得大但延迟和稳定性不占优。同样是 68 元，9929 给你 50Mbps 优化线路，4837 给你 300Mbps 普通线路，选哪个取决于你更怕慢还是更怕断。

第三层是流量和带宽的取舍。不限流量套餐看起来省心，但带宽通常被压得很低——9929 不限流量 Lite 只有 20Mbps，月付 498 元。花 498 元买 20Mbps，只有真正 24 小时跑满带宽的人才划算，普通用户买 68 元的 50Mbps 固定流量版更实际。

按年付算，账更清楚：美国 9929 精简版月付 68 元，一年 816 元；同线路的年付特价版 499 元/年，省 317 元，代价是月流量从 1000GB 降到 600GB。如果你每月跑不到 600GB，这 317 元纯属白省。

## 关于丽萨主机价格的常见问题

**月付还是年付？**
新用户先月付一个月，确认线路和 IP 符合预期再转年付。年付叠优惠码约 72 折，长期用确实省，但前提是这台机器你真的会用满一年。不确定的话，48 小时退款窗口比年付折扣更值钱。

**优惠码怎么用，续费还有效吗？**
结算页面找到优惠码输入框，填 `TS-CBP205DQJE`，全场 9 折。这个码续费同样有效，不是一次性新客券。季付、年付、二年付的周期折扣会自动生效，和优惠码叠加，不需要额外操作。

**年付到底能省多少？**
以官方举例的 88 元/月套餐算：月付加码 79.2 元/月，年付加码约 63.4 元/月、758 元/年，一年省约 190 元。周期越长折扣越深，二年付叠码约 63 折，但锁定时间也翻倍。

**哪个节点国内访问最快？**
香港三网直连 CMI/CU2/CN2 延迟最低，三网都有优化。美国 9929 三网回程优化，国内访问稳定。新加坡、台湾、英国属于非大陆优化线路，需要配香港或日本中转。

**能装 Windows 吗？**
可以，官网多个产品页明确标注支持安装 Windows。具体到某个套餐是否支持，下单前在产品页确认。

**为什么同一套餐在不同网站看到的价格不一样？**
第三方测评站常用“折后价”口径，官网展示的是标价，两者混着看会乱。以官网购物车结算页为准，那里显示的是你实际要付的金额。另外部分套餐标着“限时特价”，本身已经让过价，再叠优惠码时实际折扣可能小于标称的 9 折，购物车里确认一眼最稳。

**新加坡的套餐为什么比测评文章里写的贵？**
早期第三方测评记录的价格和官网当前标价存在差异，以官网为准。促销位和限售名额会变动，看到的价格就是当下的价格。

选丽萨主机这件事，本质上是在为 IP 属性付钱，不是为 CPU 核数付钱。想清楚你要的是干净 IP、低延迟线路，还是大带宽，价格表上每一档的差异就都能对上号。拿不准就先买月付，48 小时内不满意退款，比对着价格表纠结一星期划算。
